MONIX
TECHNICAL DOCUMENTATION INDEX

PURPOSE

This directory contains technical documentation for Monix. It is separate from the product overview, product specification, development status, and release history so that technical material can evolve without mixing product definition with implementation notes.

DOCUMENTATION AREAS

AI.txt
AI-related design and integration notes.

Architecture.txt
System architecture and component boundaries.

Build and Release.txt
Build, packaging, and release information.

Configuracion.txt
Configuration and setup information.

Debugging.txt
Debugging tools, methods, and diagnostics.

Logging.txt
Logging design and implementation guidance.

Monitoring.txt
Monitoring and telemetry documentation.

Performance.txt
Performance requirements, measurement, and optimization.

Security.txt
Security architecture and implementation guidance.

Shader System.txt
Shader runtime and rendering-system documentation.

State and Snapshot.txt
State handling and snapshot-related behavior.

Testing.txt
Testing strategy, coverage, and validation.

User Interface.txt
User-interface architecture and behavior.

DOCUMENT RULE

Technical documents must distinguish between implemented behavior, planned work, and unresolved decisions. They must not silently redefine the product specification.
