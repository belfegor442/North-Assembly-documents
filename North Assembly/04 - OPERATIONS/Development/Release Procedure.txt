PURPOSE

This procedure sets out the normal path for taking a North Assembly product from development to a stable release. It is meant to keep releases predictable and traceable without adding unnecessary process to routine work.

1. RELEASE STATES

DEVELOPMENT -> TESTING -> RELEASE CANDIDATE -> STABLE RELEASE

A product may skip a state when there is a documented reason and the associated risk is understood and accepted.

2. PRE-RELEASE

[MANDATORY]
The release version must be clearly identified before the release is prepared.

[MANDATORY]
Known critical defects affecting security, data integrity, or essential operation must be reviewed before release. A release must not proceed as though these defects do not exist.

[MANDATORY]
Release artifacts must be built from the source revision intended for that release.

[RECOMMENDED]
Release notes should cover the changes users are likely to care about, including important fixes, known issues, and compatibility information.

3. VALIDATION

[MANDATORY]
The tests required for the product must pass, or an explicit exception must be recorded and accepted by the responsible person.

[MANDATORY]
Releases containing security-sensitive changes must receive an appropriate security review.

4. PUBLICATION

[MANDATORY]
The version published to users must match the version recorded by the project.

[MANDATORY]
Stable releases and development builds must remain clearly distinguishable.

[RECOMMENDED]
Important release artifacts should be signed or otherwise integrity-verified when the product and distribution method support it.

5. ROLLBACK

[MANDATORY]
Critical releases must have a recovery or rollback path when the product architecture and distribution method make one reasonably possible.

6. POST-RELEASE

[RECOMMENDED]
Release health should be checked after publication, particularly for changes that affect stability, compatibility, security, or data handling.

[MANDATORY]
Material incidents caused by a release must be documented and handled according to the incident-response procedure.
